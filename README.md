# 📋 TaskManager

A simple Android application developed as part of the **Nova Era Tech** learning platform. This project was created to complete practical challenges while applying Android development best practices and strengthening native Android skills.

## 🚀 About the Project

TaskManager is a CRUD application that allows users to manage their daily tasks in a simple and intuitive way.

The project focuses on building a solid foundation in Android development by implementing common architecture patterns and Jetpack components.

## ✨ Features

* ➕ Create new tasks
* 📋 View all saved tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* 📱 Clean and user-friendly interface
* 💾 Local data persistence using Room Database

## 🛠️ Technologies Used

* **Kotlin**
* **Android SDK**
* **XML Layouts**
* **Fragments**
* **Navigation Component**
* **RecyclerView**
* **View Binding**
* **MVVM (Model–View–ViewModel)**
* **Room Database**
* **Coroutines**
* **Material Design Components**

## 📚 Learning Objectives

This project was built to practice:

* Building multi-screen Android applications
* Working with Fragments and Navigation
* Implementing the MVVM architecture
* Managing local data with Room
* Using Coroutines for asynchronous operations
* Displaying dynamic lists with RecyclerView
* Applying View Binding for safer UI interactions
